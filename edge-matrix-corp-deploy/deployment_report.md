### Step 3: Connect GoDaddy Domain

#### For Vercel:

1. In your Vercel project dashboard → **Settings** → **Domains**
2. Add your domain: `www.edgematrixcorp.com`
3. Vercel will give you DNS records to configure

4. Go to [GoDaddy DNS Management](https://dcc.godaddy.com/manage/dns):
   - **Option A (Recommended — CNAME)**:
     - Add a `CNAME` record:
       - Name: `www`
       - Value: `cname.vercel-dns.com`
       - TTL: 600
     - Add an `A` record for root domain:
       - Name: `@`
       - Value: `76.76.21.21`
       - TTL: 600

   - **Option B (Nameservers — full control to Vercel)**:
     - Change GoDaddy nameservers to Vercel's:
       - `ns1.vercel-dns.com`
       - `ns2.vercel-dns.com`

5. Wait for DNS propagation (up to 48 hours, usually 15-30 minutes)
6. Vercel will auto-provision an SSL certificate

#### For Railway:

1. In Railway project → **Settings** → **Networking** → **Custom Domain**
2. Add: `www.edgematrixcorp.com`
3. Railway provides a CNAME target
4. In GoDaddy DNS:
   - Add `CNAME` record:
     - Name: `www`
     - Value: (Railway CNAME target)
     - TTL: 600
